# MuseScore 用 Stream Deck アクション一覧

Stream Deck プラグインで提供する「単体ボタン」の候補。

この一覧では、ボタンの配置やフォルダ構成は決めない。ユーザーが Stream Deck 側で自由に配置できるアクション群として設計する。

## 方針

- MuseScore のパレット項目は、公式の既定パレット単位で整理する。
- `n` を含む操作は、ボタンを押した後にMuseScore側のダイアログで入力する。
- 「前／後」「初め／終わり」のように選択肢がある操作は、1つの汎用アクションに設定項目を持たせる。
- 入力モード、ボイス、メトロノーム、表示／非表示などは状態を持つアクションとして扱う。
- 具体的な MuseScore のショートカット、メニューコマンド、拡張 API との対応は実装段階で検証する。

## 1. 音価

- 各種音価への切り替え

音価の候補は MuseScore 側で利用できるものに合わせて設定する。必要に応じて、音価ごとの専用アクションと、音価を選択できる汎用アクションの両方を検討する。

## 2. 音符・臨時記号の操作

- 付点
- 複付点
- シャープ
- フラット
- ナチュラル
- ダブルシャープ
- ダブルフラット

## 3. タイ・スラー・アーティキュレーション

- タイ
- スラー
- スタッカート
- アクセント
- 縦アクセント
- テヌート

## 4. 連符・符幹・声部

- `n` 連符（2〜9はショートカット、任意のnはMuseScoreのダイアログ）
- 符幹の反転
- `n` 声部への切り替え
- コード入力（コード記号）

Stream Deckには任意の `n` を保存せず、`任意のn連符` ボタンでMuseScoreの `Add → Tuplets → Other...` ダイアログを開き、比率や番号をMuseScore側へ入力する。

## 5. 入力モード

- 選択モード
- 音価入力モード
- 音名入力モード

入力モードは、現在のモードがキーの状態表示に反映されるトグル／選択型アクションとして設計する。

## 6. 小節操作

- 選択範囲の前または後に `n` 小節追加
- スコアの初めまたは終わりに `n` 小節追加

追加位置だけをStream Deckで選び、ボタン後にMuseScoreの小節数ダイアログへ `n` を入力する。

## 7. 選択範囲・和音操作

- 選択範囲をスラッシュで埋める
- 和音を分散
- 和音を集約

「和音を分散」「和音を集約」は、MuseScore 上での正式なコマンド名と動作対象を実装時に確認する。

## 8. 表示・ナビゲーション

- ズームイン
- ズームアウト
- ミキサー表示
- ページ設定

表示切り替え系のアクションは、表示状態に応じてボタン画像やタイトルを変更できるようにする。

## 9. 再生・メトロノーム

- 再生
- 停止
- 巻き戻し
- メトロノーム

メトロノームはオン／オフ状態を表示できるトグル型アクションとする。

## 10. ファイル操作

- 保存
- 名前をつけて保存

「名前をつけて保存」は、MuseScore の標準ダイアログを開く操作として扱う。

## アクション種別の仮分類

実装時の Stream Deck アクションリストでは、次のような分類を検討する。

- `MuseScore: Note Value`
- `MuseScore: Accidental`
- `MuseScore: Articulation`
- `MuseScore: Tuplet`
- `MuseScore: Voice`
- `MuseScore: Input Mode`
- `MuseScore: Measure Operation`
- `MuseScore: Selection Operation`
- `MuseScore: View Command`
- `MuseScore: Playback`
- `MuseScore: File Command`

個別項目をすぐ配置できる専用アクションと、設定画面から対象を選ぶ汎用アクションのどちらを採用するかは、実装時に操作感を比較して決める。

## 11. パレット項目候補

MuseScore 4.7 の標準パレットに対応する項目。ここでは、ユーザーが指定した項目を中心に、パレット単位で整理する。

### 装飾音符（Grace Notes）

- スラッシュ付き 8 分音符
- スラッシュ付き 16 分音符
- スラッシュ付き 32 分音符

実装上は「装飾音符を選択位置へ追加」アクションとし、将来的に通常の装飾音符、前打音、後打音などを汎用選択できるようにする。

### 線（Lines）

- 1 番括弧
- 2 番括弧
- 2 番括弧・解放型
- staff
- system
- 8va
- 8vb
- 15ma / 15va
- 15mb / 15vb

線は開始位置と終了位置を必要とするため、単一の音符へ付ける記号とは分けて扱う。選択範囲がある場合はその範囲に適用し、範囲がない場合のエラー表示も必要。

### ブレスと休止（Breath's & Pauses）

- フェルマータ
- カエスーラ

### アルペジオとグリッサンド（Arpeggios & Glissandi）

- アルペジオ
- 上向きアルペジオ
- 下向きアルペジオ
- フォール（Fall）
- ドゥイット（Doit）
- プロップ（Plop）
- スクープ（Scoop）
- スライドアウト・ダウン
- スライドアウト・アップ
- スライドイン・アバブ
- スライドイン・ビロウ
- 上記 4 種類の rough バージョン

グリッサンド系は始点・終点の選択を必要とする可能性がある。アルペジオ系は和音または音符の選択を必要とするため、適用条件をアクションごとに定義する。

### 音部記号（Clefs）

- ト音記号
- ヘ音記号
- ト音記号 8va
- ト音記号 8vb
- ト音記号 15va
- ト音記号 15vb
- ヘ音記号 8va
- ヘ音記号 8vb
- ヘ音記号 15va
- ヘ音記号 15vb
- ハ音記号

ハ音記号は複数の位置・種類があるため、最終的には汎用の「音部記号を選択」アクションを用意する。

### 調号（Key Signatures）

- 標準の 15 種類
- 無調号／無調性の項目（正式名称と動作は MuseScore 上で確認）

調号カードの表示は長調名ではなく、MuseScore公式パレットと同じく、五線上にシャープ／フラットが並ぶ記号を使う。

### 拍子記号（Time Signatures）

- デフォルトパレットにある全項目
- 2/2、2/4、3/4、4/4、5/4、6/4、3/8、6/8、9/8、12/8、コモンタイム、アラ・ブレーヴェ

拍子記号は「拍子記号」カテゴリの項目カードから選択する。自由検索用アクションは提供しない。

### テンポ（Tempo）

- 各種「音符 = 数値」テンポ記号
- Swing
- Straight
- rit.
- a tempo
- accel.

「音符 = 数値」は音符の種類と BPM を設定できるテンポアクションとして設計する。Swing、Straight、rit.、a tempo、accel. はパレット項目アクションとして扱う。

### 強弱記号（Dynamics）

- ppp
- pp
- p
- mp
- mf
- f
- ff
- fff
- fp
- sffz
- crescendo
- diminuendo
- クレッシェンド・ヘアピン（`<`）
- ディミヌエンド・ヘアピン（`>`）

`cresc.`、`dim.` の文字付き記号と、`<`、`>` のヘアピンは別項目として扱う。ヘアピンは線と同様に範囲選択が必要。

### テキスト（Text）

- 譜表テキスト
- 段テキスト
- 発想標語
- 練習番号
- mute
- open
- 楽器変更
- pizz.
- arco

テキストは、固定文字を追加する専用アクションと、ユーザーが文字列を設定できる汎用テキストアクションを分ける。

### 繰り返しとジャンプ（Repeats & Jumps）

- 直前の小節の繰り返し：1 小節
- 直前の小節の繰り返し：2 小節
- 直前の小節の繰り返し：4 小節
- セーニョ
- コーダ
- Fine
- To Coda
- D.C.
- D.S.
- 繰り返し開始線
- 繰り返し終了線
- 繰り返し開始・終了の両面

直前の小節の繰り返しは、MuseScore 上の正式な名称と適用単位を確認する。繰り返し開始・終了は、既存の小節線を変更する操作か、パレット記号を追加する操作かを区別する。

### 縦線（Barlines）

- 縦線
- ダブルバー
- 点線
- 終止線

「終止線」は通常の終止線と、必要に応じて反復終止線などの派生項目を分けて検討する。

### レイアウト（Layout）

- 段区切り
- ページ区切り
- セクション区切り

これらは選択位置または選択範囲に適用する。区切りの追加後にレイアウト更新が必要かどうかは、MuseScore の動作を確認する。

ユーザー指定項目に加え、実装ではMuseScore 4.7の既定パレット順に次のカテゴリも追加した。

- Accidentals（追加の臨時記号）
- Articulations（追加のアーティキュレーション）
- Barlines
- Beam Properties（連桁属性）
- Brackets（括弧・ブレース等）
- Breath's & Pauses
- Clefs
- Dynamics
- Fingering（運指）
- Fretboard Diagrams（フレットボード図）
- Grace Notes
- Guitar（ギター関連）
- Harp（ハープ関連）
- Keyboard（鍵盤関連）
- Key Signatures
- Layout
- Lines
- Noteheads（符頭）
- Ornaments（装飾記号）
- Pitch（音高関連）
- Repeats & Jumps

Accordion、Bagpipe embellishments など、特定楽器向けのカテゴリも存在するため、対象楽器を広げる場合は別途追加する。

## 13. パレットアクションの設計方針

Stream DeckにはMuseScore公式パレットごとに1つのカテゴリ別アクションを登録する。アクションをキーへ置くと、プロパティインスペクターにそのカテゴリの固定項目カードが表示され、選択したカードの公式記号アイコンをキーへ反映する。自由検索用アクションや、ユーザーが検索語を入力する設定欄は提供しない。

## 14. 適用条件の分類

パレット項目は、選択状態によって必要な処理が異なる。

- 音符・休符へ追加：フェルマータ、スタッカート、装飾音符など
- 和音へ追加：アルペジオなど
- 始点と終点が必要：スラー、グリッサンド、ヘアピン、線など
- 小節または範囲へ追加：繰り返し、区切り、レイアウトなど
- テキスト入力が必要：発想標語、テンポ、楽器変更など

アクション実行時に対象が不適切な場合は、何もしないのではなく、Stream Deck 側または MuseScore 側へ短いエラー通知を出す。

## 調査メモ

- MuseScore 4.7 の公式拡張 API は、旧来のプラグイン API とは別に、JavaScript マクロと QML フォームを中心とする API v2 を案内している。
- MuseScore の公式資料では、パレット記号の多くは検索・選択操作から追加できる一方、選択範囲が必要な記号もある。
- 既存のショートカットだけで扱える項目と、パレットまたは MuseScore 拡張経由で扱う項目を実装時に分離する。
- パレットの名称や収録項目はワークスペース、言語、MuseScore のバージョンで変わる可能性があるため、最終的には 4.7.4 の実機表示を正とする。

## プロトタイプ実装状況

Stream Deckプラグインでは、キー配置やフォルダ構成を固定しない。通常操作は「操作」アクション、パレットは公式分類に対応する19個のカテゴリ別アクションとして実装した。各カテゴリのプロパティインスペクターで固定項目カードを選ぶと、表示・固有アイコンが同時に切り替わる。収録149項目はMuseScore公式の`MusescoreIcon.ttf`または同梱SMuFLフォントから抽出した記号を使い、UIアイコンフォントに対応する項目はMuseScore Studio実画面と同じ輪郭を優先する。

## 実装状況

通常操作は「操作」アクション、パレットはMuseScore公式分類に対応する19個のカテゴリ別アクションとして実装済みです。149項目を固定カードから選択でき、選択した公式フォント由来の記号アイコンをキーへ反映します。

複付点、ダブルシャープ、ダブルフラット、コード入力、任意のn連符、小節数、テキスト内容のように値が都度変わるものは、専用アクションまたはボタン後のMuseScore側入力へ委ねます。自由検索アクションは提供しません。

実行部分はmacOSの`osascript`でMuseScoreへ公式ショートカット、メニュー操作、パレット選択を送ります。
