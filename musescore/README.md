# MuseScore Control for Stream Deck

MuseScore Studio 4 を macOS の Stream Deck から操作するプラグインです。ボタン配置やフォルダ構成は固定せず、ユーザーが各キーへアクションを置いて内容を選びます。

## 使い方

### 通常の操作

Stream Deck のアクション一覧から「操作」をキーへ置き、プロパティインスペクターで音価、入力モード、連符、再生、保存、コード入力などを選びます。選択するとキー画像がその操作固有のアイコンへ自動的に変わります。

### パレット項目

MuseScore Studio の既定パレットと同じ次の分類で、アクションを用意しています。

- 装飾音符、装飾記号、トレモロ、ギター
- 線、ブレスと休止、アルペジオとグリッサンド
- 音部記号、調号、拍子記号、テンポ、臨時記号
- 強弱記号、アーティキュレーション、テキスト、鍵盤
- 繰り返しとジャンプ、縦線、レイアウト

カテゴリをキーへ置くと、プロパティインスペクターにそのパレットの項目がアイコン付きカードで表示されます。カードを選んだ瞬間に、Stream Deckのキーも同じ記号へ更新されます。149項目を収録し、MuseScore公式のUIアイコンフォント／SMuFLフォントから抽出した個別アイコンを優先して表示します。

### MuseScore側で値を入力する操作

- 「任意のn連符」はMuseScoreの連符ダイアログを開きます。比率や数値はボタンを押した後に入力します。
- 「小節を追加」は追加位置だけをStream Deck側で選び、小節数はMuseScore側のダイアログへ入力します。
- 「テキスト入力」は種類だけを選び、内容はボタンを押した後にMuseScore上で入力します。

## 主な対応操作

- 音価、付点、臨時記号、タイ、スラー、主要なアーティキュレーション
- 2〜9連符、任意のn連符、符幹反転、ボイス1〜4
- 音名／音価／再入力／挿入／選択モード、コード記号入力
- 小節追加、削除、反復、スラッシュ、分散、集約
- ズーム、ミキサー、パレット、ページ設定
- 再生、停止、巻き戻し、メトロノーム
- 保存、名前をつけて保存
- 譜表／段／発想標語／テンポ／練習番号の入力

## ビルドと検証

このリポジトリのルートで実行します。

```sh
npm install
npm run build
npm run validate
npm run pack
```

開発中は次でStream Deckへリンクできます。

```sh
streamdeck link plugin/com.codex.musescore-control.sdPlugin
streamdeck restart com.codex.musescore-control
```

## 権限と実装上の注意

プラグインはmacOSのSystem Eventsを使ってMuseScoreへキー入力やUI操作を送ります。初回は「システム設定 → プライバシーとセキュリティ → アクセシビリティ」でStream Deckを許可してください。

パレット項目はMuseScore公式のパレット選択を内部的に使います。ユーザーが検索語を入力する必要はなく、カテゴリ内の固定項目カードから選択します。カード選択時にWebSocketがまだ接続中でも、選択内容を保留して接続後に反映します。
